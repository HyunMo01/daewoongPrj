# 다른 사람이 접속할 수 있는 도메인으로 배포하기

Firebase **Hosting**을 사용하면 무료로 **https://프로젝트ID.web.app** 주소를 받을 수 있고, 다른 사람도 그 주소로 접속할 수 있습니다.

---

## 1. 필요한 것

- 이미 **Firebase 프로젝트**가 있고 **.env** 설정이 끝나 있어야 합니다.
- **Node.js 20 이상** (Firebase CLI가 Node 18에서 동작하지 않을 수 있음. 배포 시에만 필요).

---

## 2. Firebase CLI 설치 및 로그인

터미널에서 한 번만 실행하면 됩니다.

```bash
npm install -g firebase-tools
firebase login
```

- `firebase login` 실행 시 브라우저가 열리면 **Google 계정**으로 로그인합니다.

---

## 3. 이 프로젝트를 Firebase 프로젝트와 연결

프로젝트 폴더에서 실행하세요.

```bash
cd c:\Users\Kang\Desktop\daewoongPj
firebase use --add
```

1. **사용할 Firebase 프로젝트**를 목록에서 선택합니다 (Firestore 쓰는 그 프로젝트).
2. **별칭**을 물어보면 `default` 입력 후 Enter (또는 그냥 Enter).

이렇게 하면 이 폴더가 해당 Firebase 프로젝트와 연결됩니다.

---

## 4. 빌드 후 배포

아래를 순서대로 실행합니다.

```bash
cd c:\Users\Kang\Desktop\daewoongPj
npm run build
firebase deploy
```

한 번에 하려면:

```bash
npm run deploy
```

- **`npm run build`**: Vue 앱을 `dist` 폴더에 빌드합니다.
- **`firebase deploy`**: `dist` 안의 파일을 Firebase Hosting에 올립니다.

완료되면 터미널에 예시처럼 나옵니다:

```
Hosting URL: https://프로젝트ID.web.app
```

이 **Hosting URL**을 다른 사람에게 공유하면 됩니다.

---

## 5. 배포된 주소 확인

- Firebase 콘솔 → **Hosting** 메뉴에서도 **사이트 URL**을 볼 수 있습니다.
- 주소 형식:
  - **https://프로젝트ID.web.app**
  - **https://프로젝트ID.firebaseapp.com**

둘 다 같은 사이트를 가리킵니다.

---

## 6. 수정 후 다시 배포

코드나 화면을 수정한 뒤 다시 배포하려면:

```bash
npm run deploy
```

또는 `npm run build` 후 `firebase deploy` 를 각각 실행해도 됩니다.

---

## 7. (선택) 커스텀 도메인 쓰기

- Firebase 콘솔 → **Hosting** → **사이트 설정** 또는 **커스텀 도메인 추가**에서  
  본인 소유 도메인(예: `www.회사도메인.com`)을 연결할 수 있습니다.
- 무료로 받은 **.web.app** 주소만 써도 다른 사람 접속에는 문제 없습니다.

---

## 요약

| 단계 | 명령어 |
|------|--------|
| 1회: CLI 설치·로그인 | `npm install -g firebase-tools` → `firebase login` |
| 1회: 프로젝트 연결 | `firebase use --add` → 프로젝트 선택 |
| 배포할 때마다 | `npm run deploy` (또는 `npm run build` 후 `firebase deploy`) |

배포 후 나오는 **Hosting URL**을 다른 사람에게 알려 주면 됩니다.

---

## "Site not found" / "사이트를 찾을 수 없음"이 나올 때

**원인:** Firebase 콘솔에서 Hosting(도메인)만 만들었고, **실제로 파일을 배포하지 않은 상태**일 때 많이 발생합니다.  
호스팅 “사이트”는 만들어졌지만, `firebase deploy`로 **dist 폴더 내용을 한 번도 올리지 않으면** 해당 주소에 아무 것도 없어서 이 메시지가 뜹니다.

**해결 순서:**

1. **빌드**  
   ```bash
   cd c:\Users\Kang\Desktop\daewoongPj
   npm run build
   ```  
   → `dist` 폴더에 `index.html` 등이 생성되는지 확인합니다.

2. **배포**  
   ```bash
   firebase deploy
   ```  
   → **"Deploy complete!"** / **Hosting URL: https://...** 가 나와야 정상입니다.

3. **Node.js 버전**  
   `firebase deploy` 실행 시 **"Firebase CLI is incompatible with Node.js v18"** 같은 오류가 나오면:
   - [Node.js 공식 사이트](https://nodejs.org/)에서 **20 LTS** 이상을 설치한 뒤,
   - 새 터미널을 열고 다시 `firebase deploy`를 실행하세요.  
   (또는 nvm 등으로 Node 20을 설치해 두고, 배포할 때만 `nvm use 20` 후 `firebase deploy` 해도 됩니다.)

4. **배포 성공 후**  
   터미널에 출력된 **Hosting URL**로 접속해 보세요.  
   같은 주소인데도 "Site not found"가 계속 나오면, 브라우저 캐시를 비우거나 시크릿 창에서 다시 열어 보세요.

---

## `firebase deploy` 시 나오는 오류 정리

### 401 / "invalid authentication credentials"

- **원인:** CLI 로그인이 안 됐거나 만료됨.
- **해결:**  
  ```bash
  firebase login
  ```  
  브라우저에서 로그인한 뒤 다시 `firebase deploy`.  
  그래도 401이면:  
  ```bash
  firebase login --reauth
  ```  
  후 다시 배포.

### "site with no site name or target name"

- **원인:** Hosting에 사용할 사이트가 지정되지 않음.
- **해결:**  
  - `firebase.json` 안 `hosting`에 **`"site": "프로젝트ID"`** 가 있는지 확인.  
    (이 프로젝트는 `"site": "daewoong-b2c53"` 로 되어 있음.)  
  - Firebase 콘솔 → **Hosting** 에서 **사이트 ID** 확인 후, 그 값과 `firebase.json`의 `site`가 같도록 수정.

### "Invalid project selection" / 프로젝트를 찾을 수 없음

- **해결:**  
  ```bash
  firebase use --add
  ```  
  목록에서 사용할 Firebase 프로젝트 선택.  
  `.env`의 `VITE_FIREBASE_PROJECT_ID` 와 같은 프로젝트를 선택하면 됨.

### 그 밖의 오류

- 터미널에 나온 **에러 메시지 전체**를 복사해 두면 원인 파악이 쉽습니다.  
  (예: 권한 부족, 사이트 ID 오타, 네트워크 오류 등)
